# Automated Code Quality Analyzer

## Overview
An automated Python code analysis tool that helps developers
identify coding issues and evaluate code quality.

## Features
- Python code input and file upload
- Automated code analysis using Pylint
- Code quality scoring
- Error and warning categorization
- Cyclomatic complexity analysis
- Issue distribution visualization
- Improvement suggestions
- Downloadable analysis reports

## Technologies Used
- Python
- Streamlit
- Pylint
- Radon
- Pandas

## Installation

1. Clone or download this repository.
2. Create a virtual environment:

   python -m venv venv

3. Activate the environment on Windows:

   venv\Scripts\activate.bat

4. Install dependencies:

   pip install -r requirements.txt

5. Run the application:

   streamlit run app.py

## Usage
1. Start the application.
2. Enter Python code or upload a Python file.
3. Click Analyze Code.
4. Review the quality score, issues, and complexity.
5. Download the analysis report.
